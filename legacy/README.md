# Legacy Prototype Archive

This directory contains historical, pre-Next.js static artifacts:
- `index.html`: Early static UI concept mockup.
- `styles/main.css`: Early static CSS stylesheet.

---

## Historical Context

These files were created during initial concept exploration prior to migrating RepoPilot to the **Next.js 14 App Router, TypeScript Strict Mode, and Monorepo Architecture** (`packages/*`, `src/app/*`).

They are preserved here purely for historical design reference and are **not** bundled, served, or utilized in the production Next.js application.
