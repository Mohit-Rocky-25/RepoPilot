## Severity Criteria
- **Blocker:** Security vulnerability, unhandled server crash, credential leak, data loss, or total failure on primary user journey.
- **High:** Core feature silently fails or produces inaccurate answers without warning.
- **Medium:** Confusing UI feedback, degraded performance, or recoverable error on edge cases.
- **Low:** Cosmetic discrepancy, minor copy typo, or harmless style irregularity.
